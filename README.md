## 🔥 About the Project

A full-fledged **OTT Platform UI inspired by Netflix** that includes:
- 🧑 User Signup and Login  
- 🔐 Admin Login Panel  
- 📤 Admin Movie Upload Form  
- 🎞️ Content by Genre (Horror, Comedy, Romance, etc.)  
- 🤖 Bonus: Fun **Jokes API page** for users to enjoy

> Designed to give a hands-on feel of a real OTT system like Netflix.

---

## 🚀 Features

- 📺 Netflix-style landing UI
- 📝 Secure login and signup forms
- 🎬 Admin can **upload content with images and video links**
- 🎭 Movies are categorized by **genre** for better UX
- 🎉 Bonus: Get a random joke using an integrated **Jokes API**

## 💡 How to Run

1. Download the repository
2. Use a local server (like XAMPP or WAMP) and move files to `htdocs`
3. Ensure PHP backend is ready (e.g., `adminlogin.php`, `signup.php`, etc.)
4. Open `admin_login.html` or `form3.html` in browser via `localhost`
